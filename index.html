Experience

Electronic Arts · EA SPORTS FC

Oct 2024 - Present

Software Engineer 3, Gameplay · Vancouver, BC

  • Own the gameplay code for the scenes that play while the ball is out (subs, celebrations, mascots, managers) on FC 26, FC 27 and the next title, seen by millions of players. Built with animation, audio, presentation and design teams.
  • Redesigned how these scenes are chosen, set up, played and skipped as my first task, with a senior engineer's guidance, which made later features easier to add. Checked it with overnight soaks, a pass over every scene, four reviewers and git bisect.
  • Traced an assert that kept showing up in soak tests to its cause: two data entries added without their own scene types meant the last two types would always fail a bounds check. Fixing the cause closed both duplicate reports.
  • Wrote a Python script that sets up a soak test on the latest build in one step, still used by other engineers five months later.
  • Co-designed a deterministic coin-toss rule: on throw-ins, gameplay skips its own scene half the time and tells other systems, so crowd chants and other teams' scenes play more often with no changes on their side. Built so later conflicts can reuse it.
  • Fixed timing bugs before launch and in live patches for FC 26 and FC 27 (5 patch fixes in my first year), like mascots walking through stadium walls. Had a high-priority patch fix in testing about 24 hours after it was escalated, in time for the patch cutoff.
  • Wrote the gameplay engineering notes and estimates for three FC 27 feature plans, and reviewed a fourth.
  • Won a Peer-to-Peer Recognition Award (Sept 2025), partly for using ChatGPT to learn our animation tools. Shared an AI prompt that documents any area of the code with all gameplay engineers, at a senior engineer's request.

Portfolio dashboard

Python, TypeScript · Oct 2026 · live demo: tylauriente.github.io/portfolio-demo

A self-hosted live dashboard for my own Wealthsimple portfolio. Prices stream from several sources and turn amber when none has confirmed them for 75 seconds. Each feed runs in its own supervised loop, so a crash restarts the loop and not the service. Applies the superficial-loss rule and CRA limits across accounts. 709 tests.

What's real in the demo

It is the dashboard's own page and build, running on a recording of its demo mode: made-up holdings, cash and alerts, with prices, charts, news and the calendar as they came from the public sources when it was recorded. There is no server behind it, so search and settings do nothing, and the recording loops.

Claude Code Dashboard

TypeScript, Electron · Oct 2026

Runs all my AI coding sessions as live tiles. A read-only watcher checks each session's claims against what actually ran and flags stalls. Rule changes for the agents go on trial and stay only if I end up correcting sessions less.

Crypto trading

Python · Mar - Oct 2026

Trading bots for DeFi exchanges (Hyperliquid, and Jupiter on Solana) with backtesting and paper trading. In the latest, an AI agent (Claude) trades a small real-money account on Hyperliquid and Strike Finance. Only one process holds the trading key, every order passes risk checks first, a halt switch stops it, and every action is logged.
