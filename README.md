# tylauriente.github.io

Ty Lauriente's resume as a web page, and a demo of his portfolio dashboard.

- `index.html`: the resume (the same content as the PDF beside it).
- `portfolio-demo/`: the dashboard's own web build, running on a recording of its demo mode (made-up holdings,
  public market data). `replay.js` stands in for the dashboard's server, so there is no backend here.
